### Conceptual gaps — not routable, tracked separately (see backend mapping §5)

Existing routes cover 100% of visible menu destinations. Backend capabilities below have **no corresponding admin management interface** — they are known backlog, not missing routes, and are outside current Arena 1–4 scope unless explicitly added by Arena 5:

- **Reporting & analytics hub** — `maturity` reports (`/internal/reports/daily|ledger|wallets|transfers|deposits|withdrawals|reconciliation|outbox|audit`) + `health-dashboard` + `operational-report.service` produce real reports; no dashboard hub UI consumes them. Backend exists, UI doesn't — by design deferred.
- **Automatic POS / terminal provisioning** — `outlet` + `terminal` services (`TerminalService`) support outlet/terminal create/suspend/reactivate/terminate via `internal/agents/:id/terminals`; no admin UI for automatic provisioning or hardware binding.
- **SMS/Email automatic triggers** — `notification` dispatcher (Brevo/Resend/Robase/Twilio/Termii) sends via templates; admin has templates/config/provider/deliveries but no rule-editor for automatic trigger mapping — handled by backend `notification-dispatcher` + `policy` engines (A7/B1/B2).
- **Disputes standalone** — `disputes` module has no dedicated tab; surfaced inside `complianceCases`/`fraudCases` only.
- **Wallet / virtual-account admin** — `wallet`, `virtual-account`, `wallets/internal` have no admin workspace (read-only financial-context only).
- **Aggregator admin** — `aggregator`/`AdminAggregatorController` exists; no aggregator management UI.
- **Partner callbacks / external settlements** — `partner`, `external-operation`, `external-settlement`, `partner-callback` have no operations inspector (beyond `bankingOperations` readiness).
- **Policy engines (A7/B1/B2)** — commercial analytics, billing, referral, revenue-recognition, API-consumer, webhook, fiscal-period engines have `product-governance` as the governance surface, not a dedicated analytics workbench.

Four prompts cover all 33 existing routable views. Uncovered areas above are explicitly **not** assigned — they remain Arena 5 backlog tracked in backend mapping §5.

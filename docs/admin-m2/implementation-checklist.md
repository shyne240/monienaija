### Compliance contract correction

An earlier UI note incorrectly stated that the case endpoint had no catalogue check or category isolation. The integration baseline has `CustomerComplianceAccessGuard`, which intersects session scopes with active role/function grants, and the service restricts returned categories and customer ID. The UI copy now reflects that contract; the additional category selector is still client-side. This source review is not a substitute for live authorization acceptance.

## 1. V1 Scope Boundary (authoritative)

**In-scope V1 (in-house NGN wallet ecosystem):** Wallet→Wallet, Agent CASH_IN/CASH_OUT, Cash→Cash, Customer/Agent onboarding, Customer funding (maker/checker), Agent funding, Ledger double-entry, Reconciliation (9 checks + trial balance), Fees/Commissions/Rewards/Limits (registries + runtime), Support tickets, Notifications (outbox + delivery + inbox), Audit, Workforce 11-role administration, Agent network (outlets/terminals), Product catalogue.

**Out-of-scope V2 (explicitly excluded, not treated as defect):** Wallet↔Bank/NIBSS, provider settlement rails, external payout, cards/dollar cards, bills/airtime/data/electricity/cable/betting, push-only delivery, non-NGN. These are not in the matrix denominator.
